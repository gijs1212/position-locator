# position-locator

Simple Tkinter-based utility to show and copy the current mouse position.

## Usage

1. Run `mouse_locator.pyw` (double-click on Windows or `python mouse_locator.pyw` on other platforms).
2. A small window displays the current cursor coordinates, refreshed every 0.5 seconds.
3. Press **Ctrl+C** while the window is focused to copy the coordinates to the clipboard.
